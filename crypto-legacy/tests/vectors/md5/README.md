# MD5 vector provenance

- **Algorithm source:** RFC 1321, *The MD5 Message-Digest Algorithm*, §3 and Appendix A.5.
- **Record:** <https://www.rfc-editor.org/info/rfc1321/>.
- **Updated security considerations:** RFC 6151, <https://www.rfc-editor.org/info/rfc6151/>.
- **Accessed:** 2026-08-27.

The public test copies all seven Appendix A.5 message/digest pairs. Hexadecimal pairs remain in
printed digest-byte order. RustCrypto `md-5` 0.11.0 is a development-only differential oracle and
is never used by library code.
