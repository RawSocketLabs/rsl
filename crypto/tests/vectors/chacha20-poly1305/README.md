## Conversion policy

RFC hex dumps (`000  xx xx …  ascii`) are converted by a mechanical script that keeps only the
hexadecimal columns in printed order; the ASCII gutter is discarded. Colon-separated and
space-separated byte lists are joined without reordering. Wycheproof fields are copied verbatim.
No fixture byte is generated by this implementation.

The `chacha20poly1305` crate 0.11.0 is a development-only differential oracle, not an
implementation dependency or a standards authority.
